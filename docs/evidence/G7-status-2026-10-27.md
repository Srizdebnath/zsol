### Why the container shows "unhealthy"

```
healthcheck: curl -sf http://127.0.0.1:8080/ready   (interval 30s, retries 3)
$ curl http://127.0.0.1:18080/ready    ->  syncing [503]
$ curl http://127.0.0.1:18080/healthy  ->  ok [200]
compose: ZEBRA_HEALTH__READY_MAX_BLOCKS_BEHIND=2
```

The status is expected and harmless. The compose healthcheck probes `/ready`, which returns 503 until the node is within 2 blocks of the tip. The liveness endpoint `/healthy` returns 200. The container will stay "unhealthy" until the sync finishes.

## 3. `z3-regtest-rpc-router-1` restart loop

```
$ docker logs --tail 30 z3-regtest-rpc-router-1
Error: error sending request for url (http://zebra:18232/)
  tcp connect error: Connection refused (os error 111)       # repeated; RestartCount=17, exit 1

$ docker logs z3-regtest-zebra-1   (zfnd/zebra:6.2.3, ZEBRA_NETWORK__NETWORK=Regtest)
04:37:49 initializing network
... DNS error resolving peer IP addresses host="testnet.seeder.zfnd.org:18233"
    "failed to lookup address information: Temporary failure in name resolution"
... empty peer list after DNS resolution, retrying after 5 seconds   (loops forever)

Earlier runs:  10-26 06:25 and 12:46 -> "Opened RPC endpoint at 0.0.0.0:18232" ~170 ms after "initializing network"
Since 10-26 17:18 and 10-27 04:37 -> never opens RPC
regtest zebra HostConfig.Dns = []
```

**Diagnosis:** the regtest Zebra (6.2.3) is stuck in `add_initial_peers` because DNS lookups of the default testnet seeders fail inside the `z3-regtest` network. This is the same "no upstream nameserver" problem that `docker-compose.testnet.override.yml` fixed for testnet with `dns:`, but the regtest project has no such override. Zebra therefore never opens its RPC port. `rpc-router`, and `zallet` too, get connection refused, exit with code 1, and restart in a loop.

**Possible fixes (not applied):**
- Add the same `dns:` override to the regtest project, or
- Set an empty initial peer list for regtest so Zebra does not try to resolve seeders.

This does not affect G7, which uses the testnet project.
